## 1. 端到端运行步骤（从 movies.txt.gz 到最终查询）

```powershell
# 0) 环境（Windows 11 + WSL2 Ubuntu 24.04）
cd C:\Users\28746\Desktop\etl-amazon
.venv\Scripts\python.exe -m pip install -r requirements.txt      # Python 3.14.7，锁 51 包
# PostgreSQL 17.11（服务 postgresql-x64-17），建库 etl_movie（postgres/postgres，仅本地）
# Airflow 2.10.4 于 WSL（hello-world DAG 实测通过）

# 1) 下载与校验源数据（记录地址/时间/大小/SHA-256）
#    movies.txt.gz (3,321,791,660 B) → data/raw/movies.txt.gz
Get-FileHash data\raw\movies.txt.gz -Algorithm SHA256   # 期望 4b6ee09e…cdcc715
#    IMDb 5 表 (1.42GB) → data/raw/imdb/*.tsv.gz（附官方 checksums.sha256）

# 2) 建表（含软外键设计、唯一约束、索引）
psql -U postgres -d etl_movie -f sql\00_init.sql        # 依次执行 sql\01..10_*.sql

# 3) 八步 ETL（Airflow DAG: etl/dags/movie_etl_dag.py；本地等价 runner）
.venv\Scripts\python.exe src\run_etl_local.py --run-id run_<YYYYMMDD>-NN
#   extract   : src/stream_review_stats.py        流式解析 7.9M 记录（~66s，内存分批）
#   crawl     : src/record_manifest.py            快照清单登记（Scrapy 波次另由窗口1执行）
#   classify  : src/classify_products.py          产品分类（movie/non_movie/collection/…）
#   merge     : src/merge_movies.py + merge_persons.py + 人工组锚定重放
#   enrich    : src/complete_release_info.py + select_fields.py   补全与字段选择
#   dedup     : src/clean_reviews.py              逻辑评论映射（~20min，7.9M 有序装载）
#   lineage   : src/build_lineage.py              血缘四表装配
#   quality_check: src/quality_check.py           10 项检查（含 manual_merge_preserved）
#   中断恢复：任意步失败/被杀后同命令加 --resume（已成功 task 全 SKIP，失败步补跑）

# 4) 查询（见 §4）
psql -U postgres -d etl_movie -f sql\queries\q1_work_editions.sql
```
