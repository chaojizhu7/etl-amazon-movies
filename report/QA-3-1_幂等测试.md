## 三、测试发现的真实缺陷（本测试的价值所在）与修复

1. **move_table 撞键静默删行**（release_facts 丢失 129 行级证据）→ 改为值感知（全同删重复/值不同 `#keep:` 留痕）；
2. **id 重铸不稳**（非人工并集每轮换号，下游 person 节点键漂移）→ 成员集签名 id 复用 + 重放 primary=旧簇 id；
3. **重放 `for nid in ids[1:]` 逻辑洞**（primary∉ids 时 ids[0] 不搬 → 32 人工组拆散，事故详情见事故修复报告）→ `for nid in ids: if nid==primary`；
4. **primary 无实体行悬挂**（UPDATE 0 行命中）→ UPDATE 后补 INSERT ON CONFLICT；
5. 合集候选 id 重铸振荡 → 复用 + 补 INSERT；
6. eval 样本被重生成冲掉标注 → 防覆盖护栏。
