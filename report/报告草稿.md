## 1. 问题定义与目标

本项目针对 Amazon 电影评论数据集，构建一条可重复运行的 ETL 流程：从 Stanford SNAP 的历史评论与产品信息中抽取全量数据，识别电影及人物实体，完成清洗、合并与信息补全，将结果装载到数据库，并保证每个最终字段可追溯到原始来源与处理过程。

【待填】最终实际交付的范围边界（全量评论 N 条、产品清单 M 个、电影作品数、人物数——以运行统计为准）。

### 2.2 规模核对

官方统计：评论 7,911,684 条、产品 253,059 个、用户 889,176 个，时间跨度 1997-08 至 2012-10。

**实测解析结果**（`src/stream_review_stats.py` 流式逐行解析，2026-11-03，耗时 66.1 秒）：

| 指标 | 官方数字 | 实测数字 | 结论 |
|------|----------|----------|------|
| 评论条数（records_read） | 7,911,684 | 7,911,684 | ✅ 一致 |
| 不同产品数（distinct ASIN） | 253,059 | 253,059 | ✅ 一致 |
| 不同用户数（distinct userId） | 889,176 | 889,176 | ✅ 一致 |
| 时间范围（reviewTime） | 1997-08 至 2012-10 | 1997-08-20 至 2012-10-25（UTC） | ✅ 一致 |

统计核对账目：**读取记录数 7,911,684 = 有效记录数 7,911,684 + 隔离记录数 0**（校验通过）。
辅助计数：空 userId 记录 0 条；评分超出 1–5 范围 0 条；含编码替换符（U+FFFD）的行 63,567 行（原始文本保留，不影响计数）。
下载完整性：文件 3,321,791,660 字节与 HTTP HEAD 一致；SHA-256 `4b6ee09ea4880f3fb197b1407d45dfb08a892fbb48a9e7a2d74aa0572cdcc715` 已记入 download_meta.json。

解析规则：记录边界为 `product/productId:` 前缀行；字段前缀识别 8 个标准字段；非前缀行视为上一字段续行（兼容 review/text 跨行）；编码异常以 U+FFFD 替换并计数，不中断解析。

**结论**：四项指标全部与官方统计一致，无需进入排查流程。重复记录检查留待任务 8 评论去重阶段专项处理。

【待填】磁盘占用实测：压缩包 3.09 GiB、解压后实际大小（decompress_and_measure.py 输出）、总占用。

#### 1. 分类体系与识别规则（v0.1）

| 分类 | 操作性定义 |
|------|-----------|
| movie | 单一叙事性影视作品（院线片/电视电影）的一次发行 |
| tv_series | 电视剧集（整季/全系列/单集/迷你剧），不与电影混计 |
| collection | **一盘多片**：同产品含 ≥2 部互不相同的作品（三部曲/合辑）；记录候选多电影映射 |
| concert | 演唱会/音乐现场/巡演录像 |
| non_movie | 非影视商品（游戏/书籍/硬件/纯音乐 CD 等） |
| other | 影音制品但非以上（教学/健身/单口喜剧/短片等） |
| pending_review | 待确认：无快照、访问受限、页面不可判、信号冲突（**证据不足不许猜**） |

**证据分层**：A 级（可单独定类）= IMDb titleType 匹配（tconst 定位，source=imdb）/ 页面剧集标记（Season N、Complete Series）/ 页面合集证据（Trilogy、多片 Genre 列表）；B 级（支持/投票）= 贡献者角色 (Director)/(Actor)、片长带（正片 70–180 分钟）、面包屑/Genre 类目、分级、部门标签。**硬性禁止**：R0 标题含 DVD/Blu-ray/VHS 等载体词**单独零证据**；R1 单片多碟（`2 Disc`/`Gift Set`/`Steelbook`）≠ 合集；R2 受限页/无快照/信号不足一律 pending_review。全页关键词（Live/DVD/4K 等）为导航广告噪声，不作证据；仅取标题/结构化字段/描述区。

**IMDb 匹配与歧义消解**（title.basics 精确匹配，规范形：NFKD、分隔符等价、冠词全局剔除、vol./pt. 展开；剥离版本后缀后匹配，全文见规则 §4）：①标题 `[YYYY]` 年份唯一命中；②**演职员消歧**——页面署名（`<title>` 人名列表/贡献者）与候选 title.principals/title.crew（nconst→name.basics）重名比对，唯一最高且 ≥2 人命中；③最具体变体优先（别名单独精确命中）；④同名碰撞过滤（无页面信号佐证的 tvEpisode/short/video 候选不参与类别竞争）；以上均不奏效再 B 级投票，仍不足 → pending_review（`imdb_ambiguous`）。

- **人工复核（2026-11-03，详见 `report/人工复核记录.md`）**：10 个 IMDb 匹配样本（5 高置信 + 5 低置信）经人工复核——高置信 5 条**全部确认正确**（演职员消歧可逐条对照 IMDb 演职员表）；低置信 5 条处置：①Soy leyenda 确认**错配**（实为 I Am Legend 2007 tt0780504 西语发行），tconst 修正留任务 4 人工确认后执行；②Jaws 确认**剥离表顺序缺陷**（"Anniversary Edition" 先剥致 "30th" 残留），已修复重跑，匹配升级为 tt0073195/movie/0.9（本次统计已刷新）；③Les Misérables in Concert 的 tconst 标 `unverified`（候选 tvEpisode 不可信），留任务 4/5 消歧；④Ben-Hur 标 `version_unverified`（1959 vs 2016 未消歧），留任务 4；⑤Spark of Insanity 标 `no_match`（reason=`seller_title_missing_artist_prefix`），不硬匹。复核结论写入 `product_classification.evidence.manual_review`（10 条），分类脚本重跑时自动保留。
- **修复影响面确认**：Jaws 剥离缺陷修复只影响分类/匹配统计（如 Jaws 一条 0.70 inferred → 0.90 evidence）；已确认的 5 条高置信结果**零变化**（同 tconst 同置信度）；评论源数据**未触碰**（movies.txt.gz SHA-256 `4b6ee09e…cdcc715` 不变，7,911,684 条 MATCH 统计不变，分类任务从不写评论表）。
- **不猜示例**：《Spider-Man 2.1》（剪辑版无 IMDb 条目）、《George A. Romero's Land of the Dead》（冠名前缀致精确匹配失败）——页面证据不足即 pending_review，不用“看起来像电影”外推；《Casablanca》等稀疏页在演职员消歧命中前同样保持 pending。
- **载体词零证据**：`[HD DVD]`/`2 Disc`/`Gift Set`/`Steelbook` 只作版本信息，不构成 movie/collection 依据（Iron Man 2 Disc、Polar Express Gift Set 均判 movie 非 collection）。
- **类目噪声**：Amazon Genre 字段实测含 "Music Videos & Concerts" 等误标（Sound of Music、Polar Express），concert 类要求标题/描述演唱会标记或 IMDb video/tvSpecial 佐证，单类目不采信。
- **评论保留**：没有电影映射的评论全部保留于源记录（7,911,684 条不动、不删、不改）；非电影/待确认产品的评论同样保留，ProductMovie 映射在任务 4 生成，缺失映射的评论仍挂在 product/edition 实体下。
- **已知局限（留 v0.2）**：标题变体极端情形（卖家自拟标题、冠名前缀、剪辑版副标题）仍会漏匹配；IMDb aka 表未下载（title.akas），别名证据仅来自产品页原文；演职员消歧对 ≥2 人重名门槛的敏感性未做参数扫描；错配/版本未消歧样本的 tconst 修正与消歧统一在任务 4 人工确认流处理。

## 7. 缺失信息补全与冲突处理

### 7.1 上映信息补全（任务6）

上映时间语义分层：作品首映/上映年份（`release_year`，precision=year）、指定地区上映日期（IMDb 基础表不提供，预期 NULL）、商品发售日期（存 edition 域，**永不充当上映日**）。补全主源 = IMDb title.basics.startYear（实测 movie 覆盖 647,293/759,812 = 85.2%，YYYY 精度）；辅助源 = IMDb title.principals/crew 用于作品匹配验证。匹配流程：标题标准化 → tconst 候选 → 年份±1/导演/类型联合验证 → 未匹配标 `no_imdb_match`。

【待填】补全运行记录：每次补全的来源、原始值、抽取时间、匹配证据、选择规则、置信度（FieldAssertion 实际行数据）。

精度标记实现：仅知年份时存 `release_year` + `precision=year`，**禁止补成 1 月 1 日**；完整上映日期字段大量 NULL，原因 `imdb_provides_year_only`（实测边界：IMDb 公开基础表只有年份）。earliest_review_time 仅作参考；条件性上界另存 `inferred_release_bound` + 推断条件 + confidence + status=inferred，不覆盖已核实值。详见 `report/数据源策略.md` 与 `report/字段覆盖矩阵.md`。
