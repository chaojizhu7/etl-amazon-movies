# snapshots/ — 页面快照与哈希索引

**放什么**：`pages/` 子目录存产品页面原始响应快照（HTML，建议 gzip 后存档）；`index.csv`（或 `.jsonl`）为快照索引，含 ASIN、URL、快照文件名、内容哈希、HTTP 状态、获取时间。

**对应作业**：任务2 产品页面采集（"保存原始响应或授权快照"、"清单至少记录 ASIN、原始 URL、最终 URL、处理状态、HTTP 状态、尝试次数、获取时间、页面快照位置和内容哈希"）。

**Git 策略**：`pages/` 快照文件全部忽略；`index.csv` 索引文件进仓库（含内容哈希，可校验）。

**当前状态**：待 Scrapy 采集启动后生成。
