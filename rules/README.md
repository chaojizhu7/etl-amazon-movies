# rules/ — 合并 / 去重 / 选择规则（带版本号）

**放什么**：
- `movie_merge_vX.Y.*`：同一电影操作性定义、候选生成与验证规则、自动合并/人工复核/不合并判定（任务4）
- `person_disambig_vX.Y.*`：人物姓名归一与消歧规则（任务5）
- `field_select_vX.Y.*`：来源冲突选择规则（任务7）
- `review_dedup_vX.Y.*`：评论去重键与核验规则（任务8）
- 每个规则文件须标注：规则版本、阈值、置信度定义、生效日期、变更记录

**对应作业**：任务4/5/7/8 的规则要求；八、"规则变化时保留决策版本"。

**命名约定**：`<类别>_v<主版本>.<次版本>.<扩展名>`，规则变更即升版本号并在提交信息中带 `[rules=vX.Y]`。

**当前状态**：待实体合并阶段开发。
